# CURSO-SENAC-
💻 Técnico em Desenvolvimento de Sistemas — Senac

Repositório dedicado à minha jornada no curso Técnico em Desenvolvimento de Sistemas do Senac.


📘 Sobre o curso
O curso Técnico em Desenvolvimento de Sistemas do Senac forma profissionais capazes de analisar, projetar, desenvolver, testar e manter sistemas de informação, atuando em todas as etapas do ciclo de vida do software — do levantamento de requisitos à implantação.

Instituição: Senac
Eixo Tecnológico: Informação e Comunicação
Modalidade: Presencial / EAD
Carga horária: ~1.200 horas
Certificação: Diploma de Técnico de Nível Médio (reconhecido pelo MEC)


🎯 Objetivos

Compreender lógica de programação e estruturas de dados
Desenvolver aplicações web, desktop e mobile
Modelar e administrar bancos de dados relacionais
Aplicar metodologias ágeis (Scrum, Kanban) no desenvolvimento
Utilizar ferramentas de versionamento de código (Git/GitHub)
Implementar boas práticas de segurança da informação
Atuar em equipe seguindo o ciclo de vida de software
