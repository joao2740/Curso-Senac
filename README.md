# Senac Course

> 🎓 Projetos e exercícios do Curso Senac de Desenvolvimento Web

## 📋 Descrição

Repositório contendo todos os projetos, exercícios e trabalhos desenvolvidos durante o curso de programação na Senac. Inclui práticas de HTML, CSS, JavaScript e frameworks modernos.

## 🛠️ Tecnologias

- **JavaScript** - Linguagem principal
- **HTML5** - Marcação
- **CSS3** - Estilos
- **Node.js** - Runtime
- **npm** - Gerenciador de pacotes

## 📁 Estrutura do Projeto

```
├── modulo-1/          # Fundamentos
├── modulo-2/          # Intermediário
├── modulo-3/          # Avançado
├── projetos/          # Projetos práticos
└── exercicios/        # Exercícios diversos
```

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/joao2740/Senac-Course.git
```

2. Navegue até o módulo desejado:
```bash
cd modulo-1
```

3. Para projetos com Node.js:
```bash
npm install
npm start
```
